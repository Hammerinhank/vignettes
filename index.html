🗓️ Tri des vignettes par mois

—
Glisse-dépose des images ici (ou clique) pour les ajouter comme vignettes.

« Analyser un dossier » affiche l'arborescence avec une case à cocher par dossier (cocher un dossier coche aussi ses sous-dossiers). Coche les dossiers voulus puis clique « Créer les vignettes des dossiers cochés ». L'arborescence reste disponible toute la session (bouton « Voir l'arborescence »), avec ses cases cochées conservées, réutilisable autant de fois que voulu ; une nouvelle analyse remplace la précédente. Après un rechargement complet de la page, il faut ré-analyser le dossier (le navigateur ne conserve pas l'accès aux fichiers).

Regroupe les vignettes d'un même jour prises à faible intervalle dans un cadre commun, repère la meilleure au score (⭐) et propose de ne garder qu'elle. Rien n'est marqué sans ton clic ; décocher rétablit l'affichage habituel.

L'export écrit un fichier JSON par mois (dossier albums/ du dépôt) listant, pour le mois, les fichiers marqués +, marqués − et non marqués, avec le texte d'album. Rien n'est déplacé ni modifié ; relancer réécrit simplement le fichier. La création réelle des albums dans Photos.app n'est pas possible depuis un navigateur : le classement exporté est destiné à être repris par l'outil qui tourne sur le Mac. Sans dépôt/jeton configuré, le fichier est proposé au téléchargement.

Le jeton reste dans le localStorage de ce navigateur uniquement — il n'est jamais publié ni transmis ailleurs qu'à l'API GitHub. Sans jeton, l'application fonctionne en local (marques et images importées mémorisées dans ce navigateur), sans synchronisation entre appareils. Avec un dépôt et un jeton, tout le contexte est sécurisé en parallèle dans des fichiers du dépôt : marques et textes d'album + état de travail (mois, filtres) dans tri-marques.json, et les images importées (fichier + métadonnées) dans vignettes-importees/ et vignettes-importees.json — de quoi tout retrouver depuis un autre appareil.

Format attendu du manifeste 
{
  "images_base": "vignettes/",           // optionnel
  "vignettes": [
    {
      "uuid": "IMG_0001",                 // identifiant unique
      "fichier": "IMG_0001.jpg",          // nom (ou URL absolue) de l'image
      "datetime": "2023-08-04T13:13:07",  // date de prise de vue (ISO)
      "personnes": ["Hélène", "Paul"],    // optionnel
      "score": 0.87,                       // optionnel (score global)
      "scores_detail": {                   // optionnel
        "nettete_sujet": 0.2, "composition": 0.1,
        "lumiere": 0.0, "cadrage": 0.05, "echec": 0.0
      },
      "hd": true, "icloud": false          // optionnel
    }
  ]
}
